# 生成卡 · 从零做一页（五步）

> 按需加载：用户要「做」页面时读本文件。共享判据（通道值域、九条原理、自检九问）在 `SKILL.md`，不复制。

**1. 只问三个问题，别连环追问。** 缺的用默认值顶上，并在交付时说明你假设了什么。

- 给谁用、在什么场景看？→ 决定信息密度
- 这一屏最重要的一个判断是什么？→ 决定唯一的视觉主张
- 有没有既有品牌色或组件库？→ 决定通道值从哪来

默认：B 端工具 → 密度高、双栏；C 端展示 → 留白大、单列居中。

**2. 先定骨架，这一步禁止碰颜色。**

- 三种骨架，只选一种：单列 720（阅读）/ 双栏 240+1fr（工具）/ 12 栏网格（后台）
- 先写 6–9 个区块名，每个一句话说清它回答什么问题
- 骨架错了，样式救不回来

**3. 再定分组——这是格式塔的主战场。**

- 把区块按「同一件事」归成 3–5 组；超过 5 组等于没分组
- 组内间距 = 组间 ÷ 3（至少要 2 倍差，否则读者读不出边界）
- 强分组用容器（底色差 + 圆角 + padding），弱分组只靠间距；容器最多嵌两层
- 同一屏里，分组手段只允许一种主导：要么全是容器，要么全是间距

**4. 最后定通道（这里才开始碰颜色）。**

- 字号 5 级：正文 / 小标题 / 标题 / 数字 / 大标题，相邻比例 1.2–1.25
- 颜色 7 个槽位，具体值由项目定；强调色只有一个，出现位置 ≤ 3 类
- 圆角 3 档、阴影 2 档；边框要么都有要么都没有，不要一半有一半没有
- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96

**5. 自检并声明。**

- 跑一遍 `SKILL.md` 的九问，每问一行：过了打勾，没过写清改法
- 交付时先说「我用了哪几条原理、分别落在哪个选择上」，再贴代码

## 骨架库（只给结构，不给颜色）

| 场景 | 骨架 | 分组策略 |
|---|---|---|
| 表单 / 设置 | 单列 480，一行一字段 | 接近律：label 距输入 4–8px，字段之间 ≥ 24px；分节用容器 |
| 列表 / 内容流 | 单列 720 或两列 | 行内紧凑、行间距 2 倍；优先删分隔线 |
| 后台 / 仪表盘 | 240 侧栏 + 12 栏 | 共同区域：一个模块一个容器；容器间距 ≥ 容器 padding 的 2 倍 |
| 落地页 | 单列居中 720，全宽 1120 | 一屏一个主张；区块之间「大留白」和「分隔线」二选一 |
| 详情页 | 主列 720 + 右栏 280 | 主次靠宽度和字号区分，不靠颜色 |
